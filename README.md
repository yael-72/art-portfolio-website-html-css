# Yaeli Art — Art Portfolio Website · HTML5 · CSS3

A multi-page portfolio website that presents an artist's work by category: paintings, still life, characters, digital art and story illustrations, plus a "how it's made" page and a contact page.

It's built entirely with **semantic HTML and hand-written CSS**, with no frameworks. The site is in Hebrew (RTL).

A screen recording of the site is included in the repository: `yaeli art הסרטת מסך.mp4`.

---

## Pages

| Page | Content |
|---|---|
| Home | Introduction and featured works |
| Paintings | Gallery of paintings |
| Still Life | Still-life works |
| Characters | Character drawings |
| Digital | Digital artwork |
| Story Illustration | Illustrations for a story |
| How It's Made | Behind-the-scenes process |
| Contact | Contact form and details |

---

## Tech stack

- **HTML5:** a shared navigation structure across all pages
- **CSS3:** a separate stylesheet per page, layout with Flexbox, gallery grids, hover effects and an RTL layout

---

## Getting started

No build step needed. Clone the repository and open `html/דף הבית.html` (the home page) in a browser.
